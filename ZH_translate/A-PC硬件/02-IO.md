# I/O

> 来源：book-rev7.pdf，第 83–85 页（中文翻译）

处理器必须与设备以及内存通信。x86 处理器提供特殊的 in 和 out 指令，从称为 I/O 端口的设备地址读取和写入值。这些指令的硬件实现基本上与读写内存相同。早期 x86 处理器有一条额外的地址线：0 表示从 I/O 端口读写，1 表示从主内存读写。每个硬件设备监控这些线路，以读取和写入其分配的 I/O 端口范围。设备的端口让软件配置设备、检查其状态并使设备执行操作；例如，软件可以使用 I/O 端口读和写来使磁盘接口硬件读取和写入磁盘上的扇区。

许多计算机架构没有单独的设备访问指令。相反，设备有固定的内存地址，处理器（在操作系统的指令下）通过读写那些地址与设备通信。事实上，现代 x86 架构对大多数高速设备（如网络、磁盘和图形控制器）使用这种称为内存映射 I/O 的技术。然而，出于向后兼容的原因，旧的 in 和 out 指令仍然存在，使用它们的传统硬件设备（如 xv6 使用的 IDE 磁盘控制器）也是如此。
