# 设备驱动

> 来源：book-rev7.pdf，第 33–44 页（中文翻译）

设备驱动是操作系统中管理特定设备的代码：它为设备提供中断处理程序，使设备执行操作，使设备产生中断，等等。驱动代码难以编写，因为驱动与它管理的设备并发执行。此外，驱动必须理解设备的接口（例如，哪些 I/O 端口做什么），而且该接口可能很复杂且文档不全。

磁盘驱动是 xv6 中一个很好的例子。磁盘驱动在内存和磁盘之间复制数据。磁盘硬件传统上把磁盘上的数据表示为编号的 512 字节块序列（也称为扇区）：扇区 0 是第一个 512 字节，扇区 1 是下一个，依此类推。为了表示磁盘扇区，操作系统有一个对应于一个扇区的结构。该结构中存储的数据往往与磁盘不同步：它可能还没有从磁盘读入（磁盘正在处理但尚未返回扇区内容），或者它可能已被更新但尚未写出。驱动必须确保当该结构与磁盘不同步时，xv6 的其余部分不会困惑。
