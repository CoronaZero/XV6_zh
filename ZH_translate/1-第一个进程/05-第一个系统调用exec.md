# 第一个系统调用：exec

> 来源：book-rev7.pdf，第 17–24 页（中文翻译）

initcode.S 的第一个动作是调用 exec 系统调用。正如我们在第 0 章所见，exec 用新程序替换当前进程的内存和寄存器，但保留文件描述符、进程 ID 和父进程不变。Initcode.S (7708) 首先向栈上压入三个值——$argv、$init 和 $0——然后把 %eax 设置为 SYS_exec 并执行 int T_SYSCALL：它在请求内核运行 exec 系统调用。如果一切顺利，exec 不会返回：它开始运行 $init 命名的程序，$init 是指向 NUL 结尾字符串 /init (7721-7723) 的指针。如果 exec 失败并返回，initcode 会循环调用 exit 系统调用，exit 肯定不应该返回 (7715-7719)。

exec 系统调用的参数是 $init 和 $argv。最后的零使这个手工编写的系统调用看起来像普通系统调用，我们将在第 3 章看到这一点。和之前一样，这种设置避免了对第一个进程的特殊处理（在这里是其第一个系统调用），而是复用了 xv6 标准操作必须提供的代码。

第 2 章将详细介绍 exec 的实现，但总体而言，它会把 initcode 替换为从文件系统加载的 /init 二进制。现在 initcode (7700) 完成，进程将运行 /init。init (7810) 在需要时创建新的控制台设备文件，然后将其作为文件描述符 0、1 和 2 打开。然后它循环：启动一个控制台 shell，处理孤立的僵尸进程直到 shell 退出，然后重复。系统启动完成。
