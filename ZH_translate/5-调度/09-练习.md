# 练习

1. sleep 必须检查 lk != &ptable.lock 以避免死锁 (2567-2570)。它可以通过替换来消除这个特例：

```c
if(lk != &ptable.lock){
    acquire(&ptable.lock);
    release(lk);
}
```

为：

```c
release(lk);
acquire(&ptable.lock);
```

这样会破坏 sleep。如何破坏？

2. 大部分进程清理可以由 exit 或 wait 完成，但我们在上面看到 exit 不能释放 p->stack。事实证明 exit 必须是关闭打开文件的进程。为什么？答案与管道有关。

3. 在 xv6 中实现信号量。可以使用互斥锁，但不要使用 sleep 和 wakeup。把 xv6 中 sleep 和 wakeup 的用法替换为信号量。评价结果。
