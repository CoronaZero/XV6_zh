# 代码：路径名

> 来源：book-rev7.pdf，第 67–81 页（中文翻译）

路径名查找涉及对 dirlookup 的一连串调用，每个路径组件一次。namei (5189) 计算路径并返回对应的 inode。函数 nameiparent 是一个变体：它在最后一个元素之前停止，返回父目录的 inode 并将最后一个元素复制到 name 中。两者都调用通用函数 namex 做实际工作。

namex (5154) 首先决定路径计算从哪里开始。如果路径以斜杠开头，计算从根开始；否则从当前目录开始 (5158-5161)。然后它用 skipelem 依次考虑路径的每个元素 (5163)。循环的每次迭代必须在当前 inode ip 中查找 name。迭代开始于锁定 ip 并检查它是一个目录。如果不是，查找失败 (5164-5168)。（锁定 ip 是必要的，不是因为 ip->type 可以实时变化——它不能——而是因为直到 ilock 运行，ip->type 才保证已从磁盘加载。）

如果调用是 nameiparent 且这是最后一个路径元素，循环提前停止，按照 nameiparent 的定义；最后一个路径元素已被复制到 name 中，因此 name 只需返回未锁定的 ip (5169-5173)。最后，循环用 dirlookup 查找路径元素，并通过设置 ip = next (5174-5179) 为下一次迭代做准备。当循环用完路径元素时，它返回 ip。
