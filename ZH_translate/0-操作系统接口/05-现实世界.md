# 现实世界

> 来源：book-rev7.pdf，第 7–16 页（中文翻译）

Unix 把“标准”文件描述符、管道以及对这些进行操作的便捷 shell 语法组合起来，是编写通用可复用程序方面的一大进步。这一思想催生了一整套“软件工具”文化，它造就了 Unix 的许多强大与流行之处，而 shell 则是第一个所谓的“脚本语言”。Unix 的系统调用接口至今仍存在于 BSD、Linux 和 Mac OS X 等系统中。

现代内核提供的系统调用远比 xv6 多，内核服务的种类也多得多。在绝大多数方面，现代源于 Unix 的操作系统并未遵循早期 Unix 将设备暴露为特殊文件的模式，例如上面讨论的控制台设备文件。Unix 的作者们继续构建了 Plan 9，将“资源即文件”的概念应用于现代设施，把网络、图形等资源表示为文件或文件树。

文件系统抽象一直是一个强大的思想，最近以万维网的形式应用于网络资源。即便如此，操作系统接口还有其他模型。Unix 的前身 Multics 以一种使其看起来像内存的方式抽象文件存储，产生了截然不同的接口风格。Multics 设计的复杂性直接影响了 Unix 的设计者，他们试图构建更简单的系统。

本书考察 xv6 如何实现其类 Unix 接口，但这些思想与概念不仅仅适用于 Unix。任何操作系统都必须把进程多路复用到底层硬件上，将进程彼此隔离，并提供受控的进程间通信机制。学习 xv6 之后，你应该能够审视其他更复杂的操作系统，并在这些系统中看到 xv6 所蕴含的概念。
